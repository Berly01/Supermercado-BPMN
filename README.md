El analista de ventas llena un formulario sobre si las ventas son positivas o negativas en el último ciclo.
En base a las ventas, se crea o no publicaciones en las redes sociales para aumentar las ventas.

La creación de publicaciones es un subproceso en el que una persona crea una publicación y esta se publica automáticamente en toda red social que tenga la empresa.
